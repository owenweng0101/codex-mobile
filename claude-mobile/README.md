# Claude 手机连接：本次交付范围

本包只保留已完成的聊天、图片、同步与界面能力。未完成的独立“目标”功能已撤下，不作为当前可用功能展示；后续如需重新接入，必须先完成独立验收。

## 保留的功能

- 在同一条桌面会话中发送普通文字、继续聊天，并读取桌面回复。
- 发送 PNG / JPEG / WebP / GIF 图片，支持只图、图文和多图；保留上传原图、发送后的预览及刷新恢复。
- 按请求编号与原生消息编号关联消息，避免重复气泡；结果不确定时只查询原请求，不自动重发。
- 读取原生历史，支持向前分页、半行写入保护和前缀锚点，避免文件重写后漏消息。
- 显示真实运行状态、耗时和任务步骤；列表运行标记位于标题左侧。对话、状态和输入框保持一致的左右边距。
- 保留输入法、固定输入区高度、草稿、未读同步和文件预览。

图片以安全的本机文件引用提供给同一会话的读取能力，不伪装成桌面原生图片附件。发送确认只说明消息已进入原生记录，不代表模型已经读完或理解图片。

## 已移除的内容

- Claude 手机端的目标设置、修改、清除入口和面板。
- 相应的公开 HTTP 接口、私有命令通道、桌面插件目标模块及专属测试。
- 为目标功能继续进行的桌面授权、重载和试验流程。

任务进度显示与“目标”控制是两回事：前者保留，后者不交付。旧聊天记录和用户上传文件不删除。

## 运行边界

手机仍使用现有 `/m/` 三合一入口。Codex、DSH 及其服务不属于这次清理范围。

Claude 手机网关由 `com.wengqiang.claude-mobile` 管理，默认端口 18903。访问口令、消息回执和上传文件保存在用户的私有 Application Support 目录，不放进源码或分享链接。

普通消息使用已安装的 `mobile-native-bridge` 桌面连接组件，源码见 [desktop-plugin](desktop-plugin/)。网关的安装或更新不会自动给 Claude 桌面会话加载该组件。组件负责用户输入和运行状态观测；模型与权限由桌面会话决定。

## 验证

```bash
npm test
```

默认测试使用临时目录、模拟传输及注入依赖，不需要真实桌面或凭据。浏览器验收以实际手机入口为准；浏览器的手机尺寸检查不等于 iPhone 真机测试。详细测试开关见 [TESTING.md](TESTING.md)。
