# 统一手机入口与共享连接

日常只使用桌面 `手机连接/手机连接.png`。扫码进入三 tab 页面，在顶部切换 Codex、DSH 和 Claude；`连接状态.txt` 显示入口及各电脑端的可用状态。

统一入口不可用时移除失效二维码、保留状态说明，恢复后自动重新生成。不会回退到两张独立二维码。二维码包含访问凭证，不能公开分享或提交 Git。

## 日常使用

1. 使用根目录的统一打开、停止和更新入口。更新与服务启停由根目录统一工具负责。
2. 保持 Mac 开机联网；使用 DSH、Claude 时，对应电脑端需要就绪。
3. 扫描 `手机连接.png`。入口地址发生变化或旧书签失效时，重新扫码。
4. 如果某个 tab 不可用，先查看 `连接状态.txt`；其他 tab 的状态分别显示。

`connection/打开国内扫码.command` 仅作为旧快捷方式的兼容入口：优先委托根目录 `打开手机连接.command`，没有该脚本时只打开同一个桌面二维码目录，不启动或重启服务。

## 二维码维护源码

维护代码已纳入 `desktop/mobile-qr/`，不再以 Application Support 中的脚本作为源码：

- `status.mjs`：通过私有 Unix socket、两个回环状态接口读取入口状态，带超时和地址校验。
- `update.mjs`：只生成统一二维码及状态文件，清理旧双码；文件原子替换、内容不变时不重写。
- `install.mjs`：从当前仓库安装 `com.wengqiang.mobile-qr`，默认预览，显式 `--apply` 才执行。

```sh
node --test desktop/mobile-qr/*.test.mjs
node desktop/mobile-qr/install.mjs --dry-run
# 部署时由统一安装流程执行；只更换 QR 定时任务：
node desktop/mobile-qr/install.mjs --apply
```

也可通过 `MOBILE_CHATS_ROOT` 指定仓库的绝对路径。安装脚本会生成适合当前机器的 LaunchAgent 路径，源码不硬编码个人目录、不携带账号或访问凭证。源码目录移动后需重新安装 QR 任务。

## 连接依赖与维护边界

共享连接承载统一页面以及三个 tab。现有运行链路包括：8797 共享入口、8796 Codex 适配器、8787 Codex API、18902 DSH 手机适配、18903 统一外壳与 Claude 手机页。各组件由根目录的统一维护流程协调，不能因删除独立快捷方式而停止对应必需组件。

`~/Library/Application Support/CodexMobileCpolar/` 保留共享连接的安装副本、隧道状态、私有 `control.sock` 及本机隧道配置。实际隧道以运行配置为准，服务的旧标签名不代表正在使用哪家隧道。旧 8798 管理页不是日常扫码入口。

不要删除或重置各应用会话、配对 token、cookie 签名密钥、隧道凭证、用户模型配置及上传数据。不要将本机 `*-receipt.json`、鉴权响应、二维码或运行目录复制到公开仓库。

完整的迁移顺序、可退役文件和独立 QR 安装说明见 [`desktop/mobile-qr/README.md`](../desktop/mobile-qr/README.md)。
